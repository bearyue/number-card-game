# Number Card Game Pro

儿童数字启蒙小游戏，固定学习 `1 ~ 9`。

## 当前玩法

- **翻牌认数字**：点击卡牌翻开，小朋友回答后由大人点击“答对了 / 答错了”。
- **找数字**：系统给出目标数字，小朋友从九宫格中找到正确数字。
- **数一数**：根据画面中的小物件数量，从多个答案里选择正确数字。

## 游戏机制

- 支持每局学习 `3 / 5 / 7 / 9` 个数字。
- 答对后保留通过状态，并增加积分和连胜。
- 答错后会给出反馈；翻牌模式下答错卡牌会重新藏起并随机换位。
- 完成整局后显示星级、积分、答对数、答错数和本地最佳成绩。
- 支持儿童友好的庆祝动画、彩纸、提示音与中文语音播报。
- 支持可选的 **龟兔赛跑倒计时**：默认关闭；开启后小乌龟会随着时间接近终点睡觉的小白兔，超时按答错处理。

## 界面与交互

- 响应式九宫格布局，适配桌面和手机。
- 大按钮、大卡牌、清晰的颜色和状态反馈。
- 顶部实时展示进度、玩法、积分和连胜。
- 可随时重玩或返回设置。
- 静态资源带版本参数，减少浏览器缓存导致的旧页面问题。

## 文件结构

- `index.html`：页面结构
- `styles.css`：视觉样式与动画
- `app.js`：游戏状态、玩法、计时、音效与交互逻辑

直接打开 `index.html` 即可运行。
